# Week 4 – Three Roads

## My Constraints

### Budget
- Free tools only.

### Skill Level
- Beginner to intermediate in React and frontend development.
- Comfortable with Git and GitHub.
- Learning web development while building AI and Machine Learning projects.

### Portfolio Needs
My portfolio should include:
- Home page
- About Me
- Projects / Case Studies
- Skills
- Contact
- GitHub and LinkedIn links

My work needs to display:
- Project screenshots
- GitHub repository links
- Live demo links (where available)
- Case studies with explanations
- Images and icons

### Dynamic Features
No backend is required yet. A static portfolio is enough for my current needs.

---

# Option 1 – React + Vite + Vercel (Chosen)

### Build
- React with Vite

### Hosting
- Vercel (Free)

### Backend
- Not required

### Pros
- Fast and modern.
- Easy to deploy.
- Great performance.
- Widely used in industry.
- Easy to add new sections and projects later.

### Trade-off
- Requires basic React knowledge.

---

# Option 2 – HTML + CSS + JavaScript + GitHub Pages

### Build
- Plain HTML, CSS and JavaScript.

### Hosting
- GitHub Pages (Free)

### Backend
- Not required

### Pros
- Very simple.
- Easy to understand.
- Minimal setup.

### Trade-off
- Harder to maintain as the portfolio grows.
- Less reusable than React components.

---

# Option 3 – Next.js + Vercel

### Build
- Next.js

### Hosting
- Vercel (Free)

### Backend
- Not required initially.

### Pros
- Excellent performance.
- SEO-friendly.
- Supports advanced features in the future.

### Trade-off
- More complex to learn.
- More than I currently need for a portfolio.

---

# Pressure Test

## What breaks if I choose the simplest option?
Using plain HTML, CSS, and JavaScript would work, but updating and maintaining the portfolio would become harder as I add more projects and case studies.

## What do I maintain if I choose the most powerful option?
Next.js offers many advanced features, but it has a steeper learning curve and would require more maintenance than my current portfolio needs.

## Can I finish in two weeks?
Yes. React + Vite is simple enough for me to complete within two weeks while still creating a professional-looking portfolio.

## Does it show my work well?
Yes. React allows me to organize my projects, screenshots, GitHub repositories, live demos, and case studies in a clean and structured way.

---

# My Decision

I chose **React + Vite with Vercel** because it is free, easy to maintain, and matches my current skill level. It allows me to present my AI and Machine Learning projects professionally while keeping the website fast and easy to update. I considered HTML/CSS/JavaScript because it is simple, but it becomes difficult to maintain as the portfolio grows. I also considered Next.js because it is powerful, but it adds complexity that I do not need right now. React + Vite is the best balance between simplicity, maintainability, and presenting my work effectively.
